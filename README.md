# 🃏 LORD-OF-MYSTERY

## اللعبة الجديدة: لورد الغامض: غاتشا

لعبة بطاقات غاتشا نصية بعالم مفتوح لأندرويد، مستوحاة من رواية **«لورد الغامض» (Lord of the Mysteries)**.

- 📁 المشروع: [`lord-of-mystery-gacha/`](lord-of-mystery-gacha/README.md)
- 🎮 نسخة ويب قابلة للعب فوراً: `lord-of-mystery-gacha/web-preview/index.html`
- 📱 تطبيق أندرويد: Kotlin — يُبنى تلقائياً عبر GitHub Actions (`.github/workflows/build-lord-gacha.yml`)
- 🤖 راوي ذكاء اصطناعي مجاني: Pollinations (بدون مفتاح) + OpenRouter + Groq + Gemini + وضع محلي

> مشروع معجبين غير تجاري. الرواية الأصلية ملك للكاتب Cuttlefish That Loves Diving.
