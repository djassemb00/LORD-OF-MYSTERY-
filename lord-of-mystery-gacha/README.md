# 🃏 لورد الغامض: غاتشا — Lord of the Mysteries: Gacha

لعبة بطاقات **غاتشا** نصية بعالم مفتوح لأندرويد، مستوحاة من رواية **«لورد الغامض» (Lord of the Mysteries)** للكاتب Cuttlefish That Loves Diving.

> مشروع معجبين غير تجاري. جميع الشخصيات والأسماء والعالم ملك لأصحابها الأصليين.

## 🎮 ماذا تفعل في اللعبة؟

- **🃏 استدعاء غاتشا**: استدعِ شخصيات وكائنات من عالم الرواية بنظام شفقة (Pity) — إلهي مضمون عند 90 سحبة، مع حركة كشف متحركة.
- **🗺️ عالم مفتوح**: 12 مكاناً (تينجن، باكلند، جزيرة سافو، بحر سونيا، الأرض المنسية، الشرق الغامض، العالم السفلي...) سافر بحرية واتخذ قرارات تغيّر العالم: السمعة، العقل، الروحانية، وأحداث دائمة.
- **📚 47 بطاقة قابلة للجمع**: مسارات الأحمق، الباب، الرائي، الشمس، الطاغية، الموت، الظلام، الحرب... من تسلسل 9 حتى تسلسل 0 (الأحمق، آدم، أمون، ميديشي، الرائي الأصلي...).
- **⚔️ معارك بطاقات تفاعلية**: كوّن فريقاً من 3 بطاقات وقاتل بالدور — هجوم، مهارة، دفاع، أو هروب — ضد أعداء يزدادون قوة حسب خطر المكان.
- **⬆️ ترقية البطاقات**: ارفع مستوى بطاقاتك حتى 10 (+15% إحصائيات لكل مستوى) بالجوهر الغامض.
- **🎯 مهام يومية**: 5 مهام تتجدد يومياً (استدعاء، استكشاف، قتال، سفر، ذكاء اصطناعي) بمكافآت.
- **🤖 راوي ذكاء اصطناعي مجاني**: يولّد القصص والحوارات وردود فعل العالم على اختياراتك — بدون أي تكلفة.

## 🤖 الذكاء الاصطناعي المجاني

اللعبة تدعم 5 مزودين (من الإعدادات ⚙️):

| المزود | مفتاح API | التكلفة |
|--------|-----------|---------|
| **Pollinations** (الافتراضي) | ❌ لا يحتاج | مجاني 100% |
| **OpenRouter** | ✅ مفتاح مجاني من openrouter.ai | نماذج مجانية |
| **Groq** | ✅ مفتاح مجاني من console.groq.com | مجاني |
| **Gemini** | ✅ مفتاح مجاني من aistudio.google.com | مجاني |
| **محلي** | ❌ لا يحتاج | يعمل دون إنترنت |

إذا فشل الاتصال لأي سبب، يتحول الراوي تلقائياً إلى الوضع المحلي — اللعبة لا تتوقف أبداً.

## 📱 البناء والتثبيت

### نسخة الويب (تجربة فورية)
افتح `web-preview/index.html` في المتصفح — اللعبة كاملة وقابلة للعب فوراً.

### تطبيق أندرويد (APK)
1. ادفع التغييرات إلى GitHub — سيبني GitHub Actions ملف APK تلقائياً (workflow: `build-lord-gacha.yml`).
2. حمّل الـ APK من تبويب **Actions → Artifacts**.
3. ثبّته على هاتفك (اسم الحزمة: `com.lordmystery.gacha`).

أو ابنِ محلياً:
```bash
cd lord-of-mystery-gacha
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```
